# pi-extensions-browser

A pi extension that adds a `/extensions` command to browse all registered extension commands in the current session.

## Features

- Groups commands by **project scope** and **user scope**
- Shows command name and source file path
- Type-to-filter search (case-insensitive substring match)
- Keyboard navigation: ↑↓ to move, ⌫ to clear filter, Esc to close

## Usage

```
/extensions
```

Opens an interactive TUI listing all extension commands.
